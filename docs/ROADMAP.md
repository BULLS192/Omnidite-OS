## Portfolio guardrails
- P0 work gets capacity first.
- No incubation work starts early without explicit re-planning.
- A milestone is complete only when its exit criterion is verified.
- Sunday review is the accountability checkpoint.
- Six-month closeout assigns every project: **Scale / Maintain / Incubate / Archive**.

## Weekly review rule
Every Sunday:
1. Compare planned gates with verifiable evidence.
2. Mark completed, partial, slipped, at-risk, or blocked.
3. Record why slippage occurred.
4. Identify any lower-priority work that stole capacity.
5. Set exactly three concrete commitments for the following week.
